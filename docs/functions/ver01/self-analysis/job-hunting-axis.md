# 機能詳細定義書：就活軸策定機能 (Ver0.1 / MVP版)

## 概要
企業選びの基準となる「軸（Must/Want）」を言語化し、管理する機能。

## 1. データ構造 (Schema Image)
- Axis
  - description (String): 必須。軸の内容（例：「完全週休2日」「モダンな技術環境」）
  - type (Enum): "Must" (譲れない) / "Want" (あれば良い)
  - priority (Int): 任意。表示順序管理用（数値で管理）

## 2. 閲覧・操作 (List & CRUD)

### 2-1. 一覧画面
- 表示形式:
  - 画面を2カラム、または上下に分割して表示
  - 上部/左側: Must要件リスト
  - 下部/右側: Want要件リスト
- 表示項目:
  - 内容テキスト
  - 編集・削除ボタン

### 2-2. 登録・編集
- 場所: 一覧画面の「軸を追加」ボタン
- 入力項目:
  - 内容（テキスト）
  - 種類（Must / Want のラジオボタン）
  - 優先度（数値入力、または登録順で自動採番）

### 2-3. 削除
- 物理削除のみ
- 注意: 後述のマッチング機能ですでに判定に使われている軸を削除する場合、その判定データも連動して削除する（Cascade）。
