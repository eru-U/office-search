# 機能詳細定義書：キャリアビジョン設計機能 (Ver0.1 / MVP版)

## 概要
3年後、5年後、10年後のなりたい姿（Will）や、仕事における価値観（キャリアアンカー）を言語化する機能。
自己分析ページのトップに配置し、常に目に入るようにする。

## 1. データ構造 (Schema Image)
- CareerVision (Userと1:1、またはProfileテーブルに統合)
  - vision_3years (Text): 3年後のビジョン
  - vision_5years (Text): 5年後のビジョン
  - vision_10years (Text): 10年後のビジョン
  - career_anchor (Text): キャリアアンカー（大切にしたい価値観）

## 2. UI/UX

### 2-1. 表示・編集エリア
- UI: 自己分析トップ画面の上部に配置される4つのテキストエリア
- 操作:
  - 閲覧モード: テキストを表示
  - 編集ボタン: 全てのフィールドを入力可能な状態にする
  - 保存: 更新を確定する
