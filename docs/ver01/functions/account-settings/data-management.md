# 機能詳細定義書：データ管理機能 (Ver0.1 / MVP版)

## 概要
登録した就活データをユーザー自身が手元に保存（エクスポート）するための機能。
サービス終了やデータ移行、バックアップの用途を想定。

## 1. 機能仕様 (Export)

### 1-1. 全データエクスポート
- 対象データ: ユーザーに紐づく全てのDBレコード（企業、面接ログ、自己分析、タスクなど）
- フォーマット: **JSON形式**
  - ※CSVはデータ構造が複雑（階層構造がある）なため、MVPでは実装コストの低いJSONを採用する。
- UI:
  - 「データをダウンロード」ボタンを配置。
  - クリックすると、現在のDBの状態をJSONファイルとしてブラウザでダウンロードさせる。
  - ファイル名例: `office-search-backup-YYYYMMDD.json`

### 1-2. エクスポートデータの構造イメージ
```json
{
  "user": { ... },
  "companies": [
    {
      "name": "株式会社A",
      "status": "INTERVIEW",
      "schedules": [ ... ],
      "memos": "..."
    }
  ],
  "selfAnalysis": { ... }
}
```
