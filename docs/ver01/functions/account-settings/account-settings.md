# 機能詳細定義書：アカウント設定機能 (Ver0.1 / MVP版)

## 概要
ログインユーザーの基本情報管理およびアカウント削除（退会）機能。
認証基盤として NextAuth.js を使用するため、複雑な認証ロジックはライブラリに委譲し、ここではユーザー情報の表示と更新に留める。

## 1. データ構造 (Schema Image)
- User (NextAuth Default + Custom)
  - name (String): 表示名
  - email (String): メールアドレス (変更不可または再認証が必要なためMVPでは変更不可とする)
  - image (String): アイコン画像URL (MVPでは外部プロバイダの画像をそのまま使用、アップロード機能なし)

## 2. 閲覧・操作 (Account Page)

### 2-1. 基本情報表示
- 表示項目:
  - ユーザー名
  - メールアドレス
  - 取得資格の一覧

### 2-2. 基本情報更新
- 編集可能項目:
  - ユーザー名 (Display Name)
  - メールアドレス
  - 取得資格の一覧
- 操作:
  - シンプルな入力フォームと「保存」ボタン

### 2-3. アカウント削除（退会）
- 機能: ユーザーデータおよび紐づく全データ（企業、メモ、ログ等）を物理削除する。
- UI:
  - 危険な操作であることを示す赤いボタン。
  - 誤操作防止のため、確認モーダルまたは「DELETE」と入力させる確認ステップを設ける。
