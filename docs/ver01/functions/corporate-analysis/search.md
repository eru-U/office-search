# 機能詳細定義書：検索・フィルタリング機能 (Ver0.1 / MVP版)

## 概要
登録した企業情報が増えてきた際に、目的の企業を素早く見つけるための機能。
複雑なクエリビルダは作らず、よく使う絞り込み条件のみをUIに配置する。

## 1. 検索・フィルタ UI (Company List View)

### 1-1. 配置場所
- 企業一覧画面の上部（ヘッダー下）

### 1-2. 検索条件項目
1. **フリーワード検索**
   - 対象: 会社名
   - UI: テキスト入力ボックス
2. **ステータス絞り込み**
   - UI: プルダウン（またはタブ）
   - 選択肢: 全て / 選考中 / 内定 / お見送り・辞退
3. **タグ絞り込み**
   - UI: プルダウン（複数選択可）
   - ロジック: OR検索（選択したタグの「いずれか」を含む企業を表示）
     - ※AND検索は実装難易度が少し上がるため、MVPではヒットしやすいORを採用推奨

### 1-3. 並び替え (Sort)
- UI: 「並び替え」プルダウン
- 選択肢:
  - **更新日順** (Desc): 最近編集した企業を上に（デフォルト）
  - **登録日順** (Desc): 新しく見つけた企業を上に
  - **志望度順** (Desc): 評価スコア（★）が高い順

## 2. 挙動仕様
- 検索条件を変更した瞬間にリストを再取得・再描画する（リアルタイムフィルタ）。
- 検索結果が0件の場合は、「該当する企業はありません」と表示する。

## 3. カットした機能（Ver0.1では作らない）
- 待遇（年収〇〇万円以上）での数値範囲検索
- AND/OR検索の切り替え機能
- 検索条件の保存機能
- 検索補完機能
