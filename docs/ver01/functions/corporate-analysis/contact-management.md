# 機能詳細定義書：連絡先・人脈管理機能 (Ver0.1 / MVP版)

## 概要
「この会社の選考で誰と会ったか」を記録する機能。
メールアドレスや電話番号などは管理せず、あくまで「名前」と「どんな人だったか」を忘れないための備忘録として機能させる。

## 1. データ構造 (Schema Image)
- KeyPerson
  - name (String): 必須。氏名（わからなければ「面接官A」などでも可）
  - role (String): 任意。役職・役割（例: 「人事」「1次面接官」「OB」）
  - memo (String): 任意。特徴や話した内容（例: 「怖そうだが話すと優しい」「野球好き」）
  - companyId (Int): 必須 (Relation)

## 2. 人脈閲覧 (List View)

### 2-1. 表示場所
- 企業詳細画面内の「人脈・担当者」セクション

### 2-2. 表示形式
- シンプルなリスト表示
- 項目: 名前 / 役職 / メモ（1行表示）

## 3. 人脈操作 (CRUD)

### 3-1. 新規登録
- UI: 「＋人物を追加」ボタン → インライン入力または簡易モーダル
- 入力項目:
  - 名前
  - 役職（テキスト入力）
  - メモ

### 3-2. 編集・削除
- リストから直接、または編集ボタン経由で修正可能
- 物理削除のみ

## 4. カットした機能（Ver0.1では作らない）
- メールアドレス、電話番号の管理フィールド
- 名刺画像のアップロード
- 連絡履歴（いつメールしたか）の管理
