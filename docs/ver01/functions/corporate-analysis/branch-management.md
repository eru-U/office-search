# 機能詳細定義書：拠点・支店管理機能 (Ver0.1 / MVP版)

## 概要
企業の「本社」および「配属可能性がある支店・勤務地」の情報を管理する機能。
外部API（Maps, Geocoding）は使用せず、単純なテキストデータとして住所をストックすることに集中する。

## 1. データ構造 (Schema Image)
- Branch
  - name (String): 必須（例：「本社」「大阪支店」）
  - address (String): 任意（住所文字列）
  - nearest_station (String): 任意（最寄駅名）
  - companyId (Int): 必須 (Relation)

## 2. 拠点閲覧 (List View)

### 2-1. 表示場所
- 企業詳細画面内の「拠点情報」セクション

### 2-2. 表示項目
- 拠点名
- 住所（ただのテキストとして表示）
- 最寄駅

## 3. 拠点操作 (CRUD)

### 3-1. 新規登録・追加
- 場所: 企業詳細画面の「＋拠点を追加」ボタン
- 入力項目:
  - 拠点名
  - 住所
  - 最寄駅

### 3-2. 編集・削除
- リストの各アイテムから編集・削除が可能
- 削除は物理削除のみ

## 4. 今後追加する機能（Future / Ver1.0以降）
- 郵便番号からの住所自動入力（日本郵便APIなどを利用）
- 通勤時間の自動計算（NAVITIME等のAPI、または簡易計算ロジック）
