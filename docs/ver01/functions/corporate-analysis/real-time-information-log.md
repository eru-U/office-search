# 機能詳細定義書：リアル情報記録機能 (Ver0.1 / MVP版)

## 概要
企業に対する定性的なメモや評価を記録する機能。
MVP段階では「書き込める場所（枠）」を用意することに専念し、リッチな機能は排除する。

## 1. データ構造 (Schema Image)
- Company テーブルに以下のカラムを追加する
  - memo (Text): 任意。長文テキスト（Markdownパースなし）
  - evaluation_score (Int): 任意。1〜5の数値（総合評価）

## 2. メモ機能 (Simple Textarea)

### 2-1. UI/UX
- 場所: 企業詳細画面のメインコンテンツエリア
- 形式:
  - 1企業につき1つの巨大なテキストエリア（メモ帳）
  - 保存ボタンを押して更新する形式
- エディタ:
  - 標準のTextareaコンポーネント
  - 文字装飾なし（Plain Text）

## 3. 簡易評価スコア
- 5段階の星（★）アイコンによる総合評価のみ実装

## 4. 今後追加する機能（Future / Ver1.0以降）
- マルチメモ機能
  - Memoテーブルを作成し、1企業に対して複数のメモを登録可能にする
- 面接（スケジュール）との紐付け
  - Memoテーブルに scheduleId を持たせ、「1次面接の時のメモ」「最終面接のメモ」として管理・表示する
  - 企業詳細画面では、それらを時系列に一覧表示する
- Markdown記法への対応（プレビュー機能）
