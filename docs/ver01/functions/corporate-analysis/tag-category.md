# 機能詳細定義書：タグ・カテゴリ管理機能 (Ver0.1 / MVP版)

## 概要
企業に対して「#リモート可」「#激務」「#技術力高い」などの属性（タグ）を付与し、分類・検索を容易にする機能。
フリーテキスト入力ではなく、マスタデータから選択する方式を採用して表記揺れを防ぐ。

## 1. データ構造 (Schema Image)
- Tag
  - name (String): 必須。タグ名（ユニーク制約）
  - companies (Relation): Companyテーブルとの多対多リレーション (Implicit Many-to-Many)

## 2. タグ付与・解除 (Company Detail View)

### 2-1. UI/UX
- 場所: 企業詳細画面の「基本情報」または「タグ」セクション
- 表示形式:
  - 登録済みの全タグが「バッジ（Badge）」として一覧表示される
  - 選択中（付与済み）のタグ: アクセントカラー（例: 黒/青）で表示
  - 非選択のタグ: グレーまたはアウトラインのみで表示
- 操作:
  - バッジをクリックすることで、ON/OFF（紐付け/解除）を即座に切り替える
  - ※「保存」ボタン不要のインタラクション（Optimistic Update想定）

## 3. タグマスタ管理 (Settings / Modal)

### 3-1. 新規タグ作成
- 場所:
  1. システム設定画面の「タグ管理」
  2. または企業詳細画面のタグエリアにある「＋」ボタン（簡易作成）
- 操作:
  - タグ名を入力して「作成」を押すだけ
  - 作成後、即座に選択可能リストに追加される

### 3-2. タグ削除
- 場所: システム設定画面の「タグ管理」
- 操作:
  - タグリストから削除ボタンを押す
  - 注意: 削除すると、全企業の紐付けも同時に解除される

## 4. 初期データ (Seed)
- アプリの初回起動時（またはDB初期化時）に、よく使いそうなタグをプリセットとして用意しておく
- 例:
  - 働き方: #リモート可, #フレックス, #副業可
  - 環境: #自社開発, #受託, #SES, #ベンチャー, #大手
  - 印象: #雰囲気が良い, #オフィスが綺麗, #給与高い

## 5. 今後追加する機能（Future / Ver1.0以降）
- タグのグループ化（カテゴリ分け）
  - 「働き方」「技術」「待遇」などのグループで見出しを分ける
- タグごとの色設定
  - 「注意タグ（#激務）」は赤、「推奨タグ（#ホワイト）」は緑など
- AND/OR検索の詳細化
