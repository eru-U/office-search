## 1. 企業研究カテゴリ

* [ ] **企業基本情報の管理**： 新規登録、編集、削除（カスケード削除対応）
* [ ] **拠点・支店情報の管理**： 本社や勤務地の住所の登録
* [ ] **連絡先・人脈管理**： 面接官やOBなどの担当者名・特徴メモの記録
* [ ] **リアル情報記録**： 企業ごとの自由記述メモ
* [ ] **志望度評価**：その企業に対する５段階の志望度評価機能
* [ ] **企業マッチング照合**： 就活軸ごとの５段階評価、および適合率の自動計算
* [ ] **タグ付け機能**： 企業に対する属性タグ（#リモート可など）の付与・解除
* [ ] **高度な検索・フィルタリング**： フリーワード、選考ステータス、タグ、複数条件ソート

---
## 2. 自己分析カテゴリ

* [ ] **キャリアビジョン設計**： 3・5・10年後の目標とキャリアアンカーの言語化
* [ ] **自己理解データ管理**： 強み・弱み、ガクチカ、資格、自己PRテンプレートの保存
* [ ] **就活軸策定**： Must（譲れない）/ Want（あれば良い）条件の整理
* [ ] **面接対策・QAログ**： 想定質問と回答案の作成、カテゴリ分け、重要項目のピン留め
* [ ] **隠れ好み発掘機能**： 登録データやメモから、潜在的な好み（キーワード）を自動抽出・提示

---
## 3. 就活（進行管理）カテゴリ

* [ ] **スケジュール管理**： カレンダー形式での選考日程・締切の表示と登録
* [ ] **タスク管理**： 期限・優先度付きToDoリスト、企業との紐付け機能
* [ ] **選考状況ヒートマップ**： 応募企業のフェーズ分布を可視化し、通過率やボトルネックを特定
* [ ] **停滞アラート**： 一定期間放置されている企業やタスクを検知し、警告アイコンや通知で知らせる

---
## 4. アカウント・共通設定カテゴリ

* [ ] **ユーザー情報管理**： プロフィール（名前・メールアドレス・資格）の表示と更新
* [ ] **アカウント削除**： 全データの物理削除（退会機能）
* [ ] **データエクスポート**： ユーザーに付随するデータのエクスポート
* [ ] **データインポート**：本人に関わるデータのインポート（ユーザーに付随）
* [ ] **外観設定**： カラーモード（Light/Dark/System）の切り替え、アクセントカラーの変更
* [ ] **タグマスタ管理**： アプリ全体で使用するタグの作成と削除
