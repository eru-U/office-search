# 機能詳細定義書：タスク管理機能 (Ver0.1 / MVP版)

## 概要
就職活動における「やるべきこと（ToDo）」を管理する機能。
高機能なタスク管理ツールではなく、アプリ内で完結させるべき単純なタスク消化に特化する。

## 1. データ構造 (Schema Image)
- Task
  - title (String): 必須
  - deadline (DateTime): 任意
  - isCompleted (Boolean): 必須（デフォルトはfalse）
  - priority (String): "高", "中", "低"
  - companyId (Int): 任意（企業に紐づかないタスクも許容する）

## 2. タスク閲覧 (List View)

### 2-1. タスク一覧画面
- 表示形式: シンプルな縦積みのリスト
- タブ切り替え: 「未完了」と「完了済み」の2タブのみ
- 並び替え: 「期限が近い順」で固定
- 表示項目:
  - チェックボックス
  - タイトル
  - 期限（日付のみ表示）
  - 企業名（企業に紐づく場合）

### 2-2. 期限切れの扱い
- アラートや通知機能は作らない
- 期限を過ぎた日付の文字色を赤くするなどのスタイル変更のみで対応

## 3. タスク操作 (CRUD)

### 3-1. 新規登録
- 場所:
  - ダッシュボード（タスク一覧エリア）
  - 企業詳細ページ（その企業専用のタスク）
- 入力項目:
  - タイトル
  - 期限
  - 優先度
  - 関連企業（企業詳細ページからの作成時は自動入力）

### 3-2. ステータス変更（完了）
- リスト上のチェックボックスをクリックして「完了」状態にする
- 完了したタスクは「完了済み」タブへ移動（非表示化）

### 3-3. 編集・削除
- 編集: タイトル、期限、優先度の修正のみ
- 削除: 物理削除（ゴミ箱機能なし）

## 4. 今後の機能（Ver0.1では作らない）
- リマインダー通知
- 繰り返しタスク
- タスクのタグ付け・カテゴライズ
- ドラッグ＆ドロップでの並び替え
