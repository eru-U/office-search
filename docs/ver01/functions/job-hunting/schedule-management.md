# 機能詳細定義書：スケジュール管理機能 (Ver0.1 / MVP版)

## 概要
企業の選考スケジュールを管理する最小限の機能。
「登録」「表示」「削除」 の3点に集中し、複雑なステータス管理やUIギミックは排除する。

## 1. データ構造 (Schema Image)
- Event
  - title (String): 必須
  - start (DateTime): 必須
  - end (DateTime): 必須
  - category (String): "面接", "締切", "説明会", "その他" (固定値)
  - memo (String): 任意 (URLなどもここに記載)
  - companyId (Int): 必須 (Relation)

## 2. スケジュール閲覧 (Calendar View)

### 2-1. 全体カレンダー
- ライブラリ想定: `react-big-calendar` や `FullCalendar` の標準機能を使用。
- 表示: 「月表示 (Month)」のみ。
- 表示項目: 「時間 + タイトル」のみ。
- 色分け: カテゴリごとの固定色（DBに色情報を持たせず、フロント側で `category` 文字列を見て色を当てるだけ）。
- クリック挙動: 該当の 「企業詳細ページ」 へ遷移する。
  - ※モーダル表示などの中間ステップは作らない（工数削減）。

## 3. スケジュール操作 (CRUD)

### 3-1. 新規登録
- 場所: 企業詳細ページの「スケジュール」セクション。
- UI: シンプルな「追加」ボタン → 標準的なフォームモーダル。
- 入力:
  - タイトル
  - 開始・終了日時
  - カテゴリ（プルダウン）
  - メモ（テキストエリア）
- 制約: 必ずその企業に紐づく。

### 3-2. 編集・削除
- 編集: 日時とタイトルの修正のみ可能。
- 削除: 「物理削除（完全に消す）」のみ。
  - ※「中止フラグ」「グレーアウト表示」などの凝ったロジックはVer0.1では実装しない。
  - ※間違って登録したものを消せればOKとする。

## 4. 今後の機能（Ver0.1では作らない）
- 週表示 (Week View)
- ドラッグ＆ドロップでの日時変更
- 中止/辞退ステータスの管理（グレーアウト）
- 複雑なURL管理（メモ欄で代用）
- 論理削除
