# 機能詳細定義書：面接対策・QAログ機能 (Ver0.1 / MVP版)

## 概要
想定される質問と回答案（Q&A）を作成・管理する単語帳のような機能。
面接本番での受け答えをスムーズにすることを目的とする。

## 1. データ構造 (Schema Image)
- InterviewQnA
  - question (String): 質問内容（例：「なぜIT業界ですか？」）
  - answer (Text): 回答案
  - category (String): "志望動機", "自己分析", "逆質問", "その他"
  - is_pinned (Boolean): よく聞かれる質問を上部に固定するフラグ

## 2. 閲覧・操作 (QA List)

### 2-1. 一覧画面
- 表示形式: カード形式のリスト
- 機能:
  - カテゴリタブ切り替え（すべて / 志望動機 / ...）
  - ピン留めされた項目を最上部に表示

### 2-2. 登録・編集
- 入力項目:
  - 質問文（必須）
  - 回答案（任意・Markdown対応なしのプレーンテキスト）
  - カテゴリ（プルダウン選択）

### 2-3. 今後追加する機能 (Future)
- 実際に聞かれた企業の記録紐付け
- 模擬面接モード（質問だけをランダム表示する機能）
