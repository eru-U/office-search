# 機能詳細定義書：自己理解データ管理機能 (Ver0.1 / MVP版)

## 概要
強み・弱み、ガクチカ、資格、志望動機テンプレートなど、ESや履歴書作成に必要なプロフィール情報を管理する。

## 1. データ構造 (Schema Image)
- Profile (Userと1:1)
  - strength (Text): 強み
  - weakness (Text): 弱み
- Episode (ガクチカ)
  - title (String): タイトル
  - content (Text): エピソード内容
  - tags (String): タグ（カンマ区切り等で簡易管理）
- Qualification (資格)
  - name (String): 資格名
  - acquired_at (String): 取得年月（テキストで保持 "2024-01" 等）
- Template (PRテンプレート)
  - title (String): テンプレート名（例：「基本の自己PR」）
  - content (Text): 本文

## 2. 各セクションの仕様

### 2-1. 強み・弱み分析
- UI: シンプルなテキストエリア2つ（強み用、弱み用）
- 操作: 随時上書き保存

### 2-2. ガクチカ（エピソードログ）
- UI: ブログ記事のようなリスト表示
- 新規登録: タイトルと本文を入力して保存
- 用途: 日記のように「今日頑張ったこと」を書き溜めて、後でESのネタにする

### 2-3. 資格リスト
- UI: シンプルなテーブル表示
- 操作: 行追加 / 削除のみ

### 2-4. テンプレート管理
- UI: タイトルと本文のリスト
- 用途: どの企業でも汎用的に使う文章のひな形を保存しておく
