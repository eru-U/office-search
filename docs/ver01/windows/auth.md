# 1. 認証・オンボーディング

## ランディングページ
概要：未ログインユーザー向けの表紙画面
- **誘導機能**：
    - ログインボタン
    - 新規登録ボタン
- **紹介機能**：
    - アプリの特徴・キャッチコピー表示
    - デモ画面のプレビュー

## ログイン・新規登録画面
概要：ユーザー認証を行うエントリー画面
- **認証フォーム**：
    - メールアドレス・パスワード入力
    - ログイン／新規登録の切り替えタブ
- **ソーシャル連携**：
    - Googleアカウントでログイン（OAuth）
- **回復機能**：
    - パスワードを忘れた方へのリンク

## 初期セットアップウィザード
概要：初回のみ表示する基本情報入力画面
- **プロフィール設定**：
    - ニックネーム入力
    - 志望業界の選択（複数可）
- **初期データ登録**：
    - 最初の「就活軸」を1つ登録
    - チュートリアル表示
