# 2. 就活管理（ホーム・全体）

## ダッシュボード（ホーム）
概要：現状と今日のタスクを把握する司令塔
- **今日のアクション**：
    - 本日の面接・イベント表示
    - 期限切れ・今日のTODOリスト表示
- **ステータスサマリ**：
    - エントリー数・内定数のバッジ表示
    - 直近閲覧した企業へのショートカット

## 企業一覧・選考状況画面
概要：全企業の進捗を管理するカンバン
- **カンバンボード**：
    - ステータス別カラム表示（書類、一次、etc）
    - カードのドラッグ＆ドロップ移動
- **リスト操作**：
    - 企業カード表示（ロゴ、社名、次回予定）
    - 絞り込み検索（業界、志望度、タグ）

## カレンダー画面
概要：月・週単位でスケジュールを俯瞰
- **カレンダー表示**：
    - 選考日程のアイコン表示
    - TODO期限の表示
- **詳細確認**：
    - 日付クリックでの詳細ポップアップ

## 全体タスク管理画面
概要：選考外の自律タスクを管理するリスト
- **タスクリスト**：
    - タスク追加（SPI、自己分析など）
    - 完了／未完了のチェック操作
- **整理機能**：
    - 優先度順・期限順ソート
    - 期限切れタスクのハイライト
