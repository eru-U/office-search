# 3. 企業研究・分析

## 企業詳細画面
概要：1社の全情報を集約・深掘りする画面
- **基本情報タブ**：
    - URLリンク、住所（GoogleMap）、メモ表示
    - 重要人物・連絡先の管理
- **分析・マッチングタブ**：
    - 就活軸適合スコアのレーダーチャート
    - 技術スタック・給与・手当の確認
- **選考対策タブ**：
    - QAリスト（逆質問・想定質問）管理
    - この企業専用のTODOリスト
    - 選考スケジュールのタイムライン表示

## 企業登録・編集モーダル
概要：企業の追加や基本情報を修正する窓
- **入力フォーム**：
    - 企業名、公式サイトURL入力
    - 業界マスタからの選択
- **ステータス設定**：
    - 現在の選考段階の初期設定

## 選考結果入力モーダル
概要：面接終了後に結果と予定を記録する窓
- **結果記録**：
    - 合否ステータス変更（通過・お祈り）
    - 次回選考日の設定
- **振り返り**：
    - 面接で聞かれたことのメモ（QAへ保存）
