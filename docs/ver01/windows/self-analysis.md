# 4. 自己分析・設定

## 就活軸・WCM設定画面
概要：企業選びの基準を定義する画面
- **軸リスト管理**：
    - 軸の追加・編集・削除
    - 優先順位の並び替え（D&D）
- **WCM設定**：
    - Will/Can/Mustのラベル割り当て

## プロフィール・資格管理画面
概要：自分の基本スペックを管理する画面
- **ユーザー設定**：
    - アイコン画像アップロード
    - アカウント情報編集
- **スペック管理**：
    - 保有資格の追加・削除（取得年月）

## マスタ管理画面
概要：タグや業界の辞書をメンテする画面
- **マスタ編集**：
    - タグマスタの編集（名称変更・削除）
    - 業界マスタの編集
    - 手当マスタの編集

# 5. システムその他

## アカウント設定画面
概要：パスワードや通知設定を行う画面
- **システム設定**：
    - パスワード変更
    - ダークモード切替
- **データ管理**：
    - 退会・全データ削除処理
